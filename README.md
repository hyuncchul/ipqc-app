# LTC 생산 현황 — GitHub Pages용

## 업데이트 방법

`production.html`, `ltc-sw.js`, `ltc-manifest.webmanifest`, `ltc-apple-touch-icon.png`, `ltc-icon-192.png`, `ltc-icon-512.png` 여섯 파일을 기존 GitHub 저장소 `ipqc-app`의 같은 폴더에 업로드합니다. `THIRD-PARTY-NOTICES.txt`도 함께 보관하세요. 기존 다른 앱의 `index.html`은 바꾸지 않아도 됩니다.

- 현황/입력: https://hyuncchul.github.io/ipqc-app/production.html
- PDA 화면: https://hyuncchul.github.io/ipqc-app/production.html?pda=1

이 HTML은 위 화면에서 직접 등록, 갱신, 종료, 조회할 수 있습니다. 누구나 로그인 없이 사용할 수 있으며 공용 서버에 전송된 자료가 모든 단말기에 공유됩니다. GitHub에는 아직 자동 업로드하지 않았습니다.

## PDA 및 오프라인 사용

1. 인터넷이 연결된 곳에서 새 파일이 적용된 주소를 열고 설비/품목 목록이 표시될 때까지 기다립니다. 최초 한 번은 온라인으로 페이지와 기준정보를 받아야 합니다.
2. 설비를 선택하면 바코드 입력란이 활성화됩니다. 스캐너는 키보드 출력과 종료 문자 Enter를 사용합니다. 잘못 읽었으면 ‘다시 스캔’을 누르거나 입력을 지운 뒤 다시 읽으세요.
3. 조회 결과 확인 후 **‘확인 후 등록 / 갱신’** 또는 수정 창의 저장 버튼을 누르면 기기에 먼저 보관하고 자동 전송합니다. 단순 스캔/조회만으로는 저장되지 않습니다.
4. 오프라인에서 저장한 자료는 앱이 열려 있을 때 인터넷이 복구되거나, 연결된 상태에서 앱을 다시 열면 자동으로 전송됩니다. 전송 실패는 약 10초 간격으로 재시도합니다. 필요하면 **‘지금 동기화’**를 누를 수도 있습니다.
5. 미전송 수가 0이면 전송이 완료된 것입니다. 다른 단말기의 변경과 충돌한 경우 ‘현재 자료와 비교’에서 확인하고 사용할 자료를 선택하세요. 확인된 자료부터 자동 전송하며, 다른 설비의 전송은 계속 진행합니다.

미전송 자료는 해당 단말기 브라우저에 저장됩니다. 전송 전에는 브라우저 데이터 삭제/초기화를 하지 마세요. 비공개 모드는 사용하지 마세요. 오프라인 현황은 마지막 서버 조회 내용이며 미전송 자료는 다른 사람에게 아직 보이지 않습니다. 설비/품목 기준정보 수정은 인터넷 연결이 필요합니다.

`ltc-sw.js`는 페이지를 오프라인으로 다시 열기 위한 파일입니다. HTTPS 및 Service Worker/IndexedDB를 지원하는 브라우저가 필요합니다. HTML만 업로드하면 페이지가 이미 열린 상태의 저장/재전송은 가능하지만, 인터넷 없이 페이지를 다시 여는 기능은 보장되지 않습니다. 로컬 파일(file://) 열기는 브라우저에 따라 저장소 지원이 다르므로 PDA에서는 위 HTTPS 주소를 사용하세요.

## 반영 내용

- 잘못된 스캔 후 삭제/재입력 시 새 입력을 읽고 이전 조회 결과가 덮어쓰지 않도록 수정
- 단말기 저장 후 자동으로 순서대로 전송, 응답 유실 시 중복 저장 방지
- 갱신 이력에 서버 등록 시각과 단말기 스캔 시각 보관

- 바코드 생산오더 뒤 선택적 추가 값 무시
- 한국어/영어/대만 번체 중국어/베트남어/인도네시아어 지원

## 설비 현황 디스플레이

상단의 ‘설비 현황 디스플레이’ 탭을 열거나 production.html?view=display로 접속하세요. 표의 27대(A02–A04, A07–A12, B13–B24, C25–C30)를 체크 여부와 관계없이 고정 위치에 표시합니다. 새 탭의 전체/정상가동/IDLE 집계는 이 27대 기준입니다. 기존 PDA 선택과 다른 탭의 집계 기준은 유지됩니다.

- 녹색 표시등: 업로드된 생산 등록 상태가 running이고 파트 넘버가 있는 설비
- 노란색 표시등(IDLE): 현재 생산 등록이 없거나 생산이 종료된 설비
- 각 설비를 클릭하면 상세 정보와 확대 표시등이 열립니다. 조회만 하며 생산 상태를 변경하지 않습니다.
- PC의 가로 화면에 집계와 5열 × 6행을 표시하며 ‘전체 화면’으로 확대할 수 있습니다. 아이폰에서는 한 줄로 보기가 기본이며, 전체 화면 보기로 기존 5열 배열을 확인할 수 있습니다.
- 화면은 10초마다 조회합니다. PDA 자료는 자동 전송이 완료되면 공유됩니다. 실제 설비 신호와 연결된 상태는 아닙니다.

## 설비 추가정보 입력

설비 현황 디스플레이에서 설비 카드를 누르면 작업자 번호, Pbin Color, P M/C, CO, ETC를 입력할 수 있습니다. 작업자 번호는 앞자리 0을 유지합니다. P M/C와 CO는 미입력/Yes/No 중 선택하며, 나머지는 직접 입력합니다.

추가정보 저장 후에는 현재 단말기 카드 하단 표에 바로 표시되고 ‘미전송’으로 표시됩니다. 인터넷에 연결되어 있으면 공용 서버로 자동 전송하고 다른 단말기에도 공유합니다. 연결이 끊겨 있으면 자료를 보관했다가 재연결 후 전송합니다. 상단의 지금 동기화 버튼으로 즉시 재시도할 수도 있습니다. 충돌이나 오류는 ‘미전송 자료 보기’에서 확인하세요. 변경 전후 내용은 갱신 이력에 보관됩니다.

추가정보는 설비별로 유지됩니다. 다음 바코드를 스캔하거나 생산을 종료해도 자동 삭제되지 않으며, 바꾸거나 비우려면 해당 설비 창에서 수정 후 다시 저장하세요. 추가정보 수정은 생산 상태와 정상가동/IDLE 집계에 영향을 주지 않습니다.

## 아이폰 앱 설치

1. 위 여섯 파일을 같은 GitHub Pages 폴더에 업로드합니다. 기존 `index.html`은 교체하지 않아도 됩니다.
2. 아이폰 **Safari**에서 https://hyuncchul.github.io/ipqc-app/production.html?view=display 를 엽니다.
3. **공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가**를 선택합니다. iOS 버전에 따라 웹 앱으로 열기 옵션이 별도로 표시되지 않을 수 있습니다.
4. 홈 화면의 **LTC** 아이콘으로 실행합니다. 처음에는 온라인에서 앱과 기준정보를 받아 주세요.

설비 현황의 **한 줄로 보기**는 27대 설비를 설비 번호 순으로 한 칸씩 세로로 보여줍니다. **전체 화면 보기**는 원래 설비 위치와 5열 × 6행 배열을 유지합니다. 위쪽의 보기 버튼으로 언제든 전환할 수 있으며 선택은 해당 기기에 저장됩니다.

생산 변경 및 미전송 자료는 단말기에 먼저 보관하고 **자동 동기화**로 공유합니다. 앱 설치 전 Safari에서 저장한 미전송 자료가 있다면 먼저 그 Safari 화면에서 업로드를 완료하세요.

Apple 설치 안내: https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios

## 비밀번호 보호
조회, 새로고침, 자동 조회, 엑셀 다운로드는 누구나 가능합니다.
수정 잠금 해제에서 관리자 비밀번호를 입력해야 스캔 저장, 정보 수정, 기준정보 변경, 엑셀 업로드를 할 수 있습니다.
5분간 터치/키보드/스크롤 조작이 없으면 자동 잠금되며 로그인 최대 시간은 8시간입니다.
잠금 상태의 미전송 자료는 보존되고, 다시 로그인하면 인터넷 연결 시 자동 업로드됩니다.
비밀번호 변경 버튼에서 현재 비밀번호와 새 비밀번호(12~128자)를 입력하세요. 변경하면 다른 기기의 기존 로그인은 무효가 됩니다.
초기 비밀번호는 별도로 제공한 보안 파일을 확인하세요. 그 파일은 GitHub에 업로드하지 마세요.
이 폴더의 파일을 GitHub Pages에 교체 업로드한 뒤 기존 화면을 새로고침하세요. 서버는 기존 공유 서버를 사용합니다.

🔧 IPQC 앱 설정 & 배포 가이드

이 가이드는 IPQC 검사 앱을 인터넷에 올리고, 여러 검사원이 동시에 사용할 수 있도록 설정하는 전체 과정을 안내합니다.
소요 시간: 약 20~30분
📱
IPQC_inspector.html NEW
검사원용 입력 앱 — 태블릿/모바일 최적화, Firebase에 데이터 저장
📊

관리자 대시보드 — 비밀번호 보호, 일일 리포트 조회, Excel 다운로드
📄

지금 보고 계신 이 파일

STEP 1. Firebase 프로젝트 만들기

1 Google 계정으로 Firebase 콘솔에 접속합니다
https://console.firebase.google.com → 로그인
2 새 프로젝트 만들기
"프로젝트 추가" 클릭 → 프로젝트 이름 입력 (예: ipqc-inspection) → Google Analytics는 "지금 사용 안함" 선택 → 프로젝트 만들기
3 웹 앱 등록
프로젝트 홈 화면에서 </> (웹) 아이콘 클릭 → 앱 닉네임 입력 (예: ipqc-web) → 앱 등록 클릭

그러면 아래와 같은 설정 코드가 나타납니다: 
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "ipqc-inspection.firebaseapp.com",
  projectId: "ipqc-inspection",
  storageBucket: "ipqc-inspection.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
⚠️ 이 값을 복사해 두세요. 다음 단계에서 사용합니다.

STEP 2. Firestore 데이터베이스 만들기

1 Firebase 콘솔 왼쪽 메뉴 → Firestore Database → 데이터베이스 만들기
2 모드 선택: 프로덕션 모드로 시작 → 위치: asia-northeast3 (서울) 선택 → 완료
3 보안 규칙 설정
Firestore → 규칙 탭 클릭 → 아래 내용으로 교체 후 게시: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 검사 데이터: 누구나 쓸 수 있고, 읽기는 금지 (앱에서만 읽도록)
    match /ipqc_inspections/{document} {
      allow create: if true;   // 검사원: 새 데이터 저장 가능
      allow read: if false;    // 일반 접근 차단 (관리자는 서버사이드에서)
    }
  }
}
💡 더 안전하게 하려면 Firebase Authentication을 추가할 수 있지만, 현재 구성으로도 관리자 대시보드의 비밀번호 보호 방식으로 충분히 보안이 됩니다.
⚠️ 위 규칙에서 read가 false이면 관리자 앱에서 읽기가 안됩니다. 테스트용으로는 잠시 allow read: if true;로 변경해도 됩니다. 실운영 시에는 Firebase Authentication 추가를 권장합니다.

STEP 3. HTML 파일에 Firebase 설정 입력

1 IPQC_inspector.html을 텍스트 에디터(메모장, VS Code 등)로 열기
2 아래 부분을 찾아서 STEP 1에서 복사한 값으로 교체: 
const FIREBASE_CONFIG = {
  apiKey: "YOUR_API_KEY",          ← 실제 값으로 교체
  authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT_ID.appspot.com",
  messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
  appId: "YOUR_APP_ID"
};
3 IPQC_admin.html에도 동일하게 적용 (FIREBASE_CONFIG 부분 교체)

추가로 관리자 비밀번호도 변경하세요: 
const ADMIN_PASSWORD = "ipqc2024!";  ← 원하는 비밀번호로 변경
⚠️ 반드시 비밀번호를 변경하세요!
기본값 ipqc2024!은 누구나 알 수 있으므로, 반드시 본인만 아는 비밀번호로 바꿔주세요.

STEP 4. 인터넷에 배포하기 (Firebase Hosting)

1 Firebase 콘솔 → 왼쪽 메뉴 Hosting → 시작하기
2 Node.js가 설치된 컴퓨터에서 터미널/명령 프롬프트를 열고: 
npm install -g firebase-tools    ← Firebase CLI 설치
firebase login                    ← Google 로그인
firebase init hosting             ← 호스팅 초기화 (public 폴더 지정)
  → "Configure as a single-page app?" → No
  → public 폴더를 현재 폴더(.)로 지정
3 HTML 파일을 public 폴더에 복사 후 배포: 
firebase deploy --only hosting
배포 완료 시 URL이 나타납니다: https://ipqc-inspection.web.app
✅ 배포 완료! 이 URL을 검사원들에게 공유하면 됩니다.
검사원 앱: https://[프로젝트ID].web.app/IPQC_inspector.html
관리자 앱: https://[프로젝트ID].web.app/IPQC_admin.html

📌 더 간단한 배포 방법 (Node.js 없이)

Netlify Drop 방법 (가장 간단):
  1. netlify.com에 접속 → 무료 가입
  2. Sites 페이지의 드래그 앤 드롭 영역에 HTML 파일 3개가 있는 폴더를 끌어다 놓기
  3. 자동으로 URL 생성됨 (예: https://happy-panda-12345.netlify.app)
  4. 커스텀 URL 설정도 가능

STEP 5. 검사원에게 배포 & 사용 방법

검사원 사용 방법:
  1. 태블릿/스마트폰 브라우저에서 검사원 URL 접속
  2. 날짜, 시간, 검사원 이름, SHIFT 입력
  3. 기본 정보 (Description, Customer 등) 입력
  4. 설비명 입력 (또는 "설비명 자동 입력" 클릭)
  5. 항목별로 측정값 입력
  6. "☁️ 앱에 저장 (서버)" 버튼 클릭 → 서버에 저장됨
  7. 필요 시 "📥 CSV 로컬 저장"으로 로컬에도 저장
관리자 사용 방법:
  1. 관리자 URL에 접속 → 비밀번호 입력
  2. 날짜 선택 후 "조회" 클릭
  3. KPI 요약, 검사원별 카드, 전체 상세 테이블 확인
  4. "📥 Excel 저장" 클릭 → 3개 시트 Excel 파일 다운로드
    • 시트1: 요약 (KPI)
    • 시트2: 원본 데이터 전체
    • 시트3: 검사원별 요약

❓ 자주 묻는 질문

질문답변
검사원이 실수로 두 번 제출하면? 두 건 모두 저장됩니다. 관리자 대시보드에서 확인 후 불필요한 건은 Firebase 콘솔에서 직접 삭제할 수 있습니다.
인터넷이 없을 때는? 입력 및 로컬 CSV 저장은 가능하지만, 서버 저장은 불가합니다. 인터넷 복구 후 JSON 백업으로 재제출하거나, CSV를 관리자에게 직접 전달하세요.
Firebase 무료 한도는? Spark(무료) 플랜: Firestore 읽기 50,000/일, 쓰기 20,000/일. 일반적인 IPQC 사용량에는 충분합니다.
비밀번호를 잊었을 때? IPQC_admin.html 파일의 ADMIN_PASSWORD 값을 수정 후 재배포하면 됩니다.
언어를 추가하고 싶을 때? IPQC_inspector.html의 I18N 객체에 새 언어 키를 추가하고, <select> 언어 목록에 옵션을 추가하세요.
